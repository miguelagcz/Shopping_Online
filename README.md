# Shopping Online — Shopping Cart UI

Interfaz de tienda online construida con HTML, CSS y JavaScript. El proyecto se centra en la presentación de productos y en la interacción de un carrito de compras directamente en el navegador.

## Características

- Catálogo de productos con imágenes, nombres y precios.
- Acción para añadir productos al carrito.
- Panel de carrito con importe total.
- Interfaz para abrir y cerrar el carrito.
- Estilos y estructura organizados en carpetas.
- Iconografía con Boxicons.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Boxicons

## Ejecutar localmente

No requiere instalación de paquetes.

```bash
git clone https://github.com/miguelagcz/Shopping_Online.git
cd Shopping_Online
```

Abre `index.html` en tu navegador o utiliza Live Server.

## Alcance

Proyecto frontend de demostración. El botón de compra no debe considerarse una pasarela de pago ni un procesamiento real de pedidos, salvo que se conecte a un backend y proveedor de pagos.

## Qué demuestra

Manipulación del DOM, eventos de usuario, actualización de elementos de interfaz, organización de archivos estáticos y construcción de una experiencia básica de carrito.
